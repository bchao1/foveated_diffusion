# Foveated Diffusion Evaluation Scripts

## Description 
- `inference.py` is the main script for generating images from a model checkpoint.
- `generate_paper_figures.py` reads images generated by `inference.py` and generates paper figures.
- `generate_metrics.py` reads images generated by `inference.py` and generates metrics.

## Usage
> `generate_metrics.py`
- `generated_images_dir`: Path to the generated images directory. Should contain a `metadata.csv` file, with the following columns: `image` and `prompt`.
- `prompt_csv_path`: Path to the prompt csv file, with the following columns: `image` and `prompt`.
- `images_dataset_path`: Path to the images dataset. `<images_dataset_path>/<image_name>.png` should be the path to the image, where `<image_name>` is the under the `image` column in the csv file given by `prompt_csv_path`.
