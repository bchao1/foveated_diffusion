## Qualitative results prompts
Subject matters that have strict structural, anatomical, or geometric rules, so that scale or strctural mismatches are easy to identify.

Here is the list of the categories and specific subject matters I just mentioned:

**1. Anatomical and Biological Forms**

* **Human Subjects:** Faces, hands, teeth, and full-body poses (especially joint alignments).
* **Animals and Creatures:** Dogs, cats, horses (especially leg joints, body length, and facial symmetry).
* **Crowds or Group Interactions:** People holding hands, hugging, or overlapping.

**2. Rigid Architecture and Engineered Environments**

* **Highly-Detailed Cities and Streetscapes:** Grids of windows, balconies, street lamps, and brickwork.
* **Interior Rooms:** Floor tiles, ceiling corners, staircases, and doorways.
* **Vehicles:** Cars, bicycles, airplanes (especially wheels, headlights, steering wheels, and dashboards).

**3. Functional Everyday Objects**

* **Symmetrical Objects:** Plates, bowls, glasses, and mugs (especially rims and handles).
* **Mechanical Tools & Instruments:** Cameras, musical instruments (like guitar strings and frets), and silverware.
* **Objects with Distinct Parts:** Chairs (four legs), eyeglasses, and open umbrellas.

**4. Typography and Symbolic Information**

* **Signs, Books, and Documents:** Any text, numbers, written documents, or street signs.
* **Clocks and Dials:** The numbering and the placement/alignment of hands on a watch or clock face.

**5. Scenes Requiring Relative Scale**

* **Subjects interacting with props:** A person holding a coffee cup, eating with a fork, or playing an instrument.
* **Foreground vs. Background interactions:** A tourist posing in front of a monument or building, where the scale of the person relative to the pathway and structure must align.

## Scripts

- `inference.py` — generate images from a model checkpoint.
- `generate_paper_figures.py` — read images generated by `inference.py` and produce paper figures.
- `generate_metrics.py` — compute FID, Precision/Recall, and CLIP scores between generated and real images.
- `extract_inception_features.py` — pre-extract and cache Inception features for a directory of images (real or generated), so that `generate_metrics.py` can skip re-extraction on subsequent runs.

---

## `generate_metrics.py`

Reads images produced by `inference.py` and computes aggregated evaluation metrics.

### Required args

| Arg | Description |
|---|---|
| `--generated_images_dir` | Directory of generated images. Must contain a `prompt_list.txt` with lines of the form `<image_name>: <prompt>`. Images are expected at `img_<image_name>.png`. |
| `--images_dataset_path` | Real image dataset directory. Must contain `metadata_test.csv` with `image` (relative path) and `prompt` columns. |
| `--metric_output_dir` | Directory where `metrics.json` and feature cache files are written. |

### Optional args

| Arg | Default | Description |
|---|---|---|
| `--foveate_real` | off | Apply per-image foveation to real images before metric computation. Reads `mask_<image_name>.png` from `--generated_images_dir`. Missing masks fall back to a center-square mask of side `GEN_W // 2`. |
| `--downsample_real` | off | Bicubic 2× downsample real images before metric computation. |
| `--batch_size` | 64 | Batch size for Inception and CLIP feature extraction. |
| `--device` | `cuda:0` / `cpu` | PyTorch device string. |
| `--debug` | off | Save a side-by-side comparison figure of generated vs real images. |
| `--debug_num_pairs` | 1 | Number of pairs to include in the debug figure. |
| `--test` | off | Smoke-test: load models, run on dummy data, check shapes, then exit. |

### Feature caches

On first run, Inception features for both generated and real images are saved to `--metric_output_dir`:

- `gen_feats_cache.pkl` — generated image features (shared by FID and PR).
- `real_feats_cache.pkl` — real image features (shared by FID and PR).

Subsequent runs with the same `--metric_output_dir` load features from cache, skipping extraction.
These caches can also be pre-built with `extract_inception_features.py`.

### Example invocations

**Baseline (no foveation):**
```bash
python generate_metrics.py \
  --generated_images_dir /path/to/generated \
  --images_dataset_path  /path/to/dataset \
  --metric_output_dir    /path/to/output
```

**With foveation applied to real images:**
```bash
python generate_metrics.py \
  --generated_images_dir /path/to/generated \
  --images_dataset_path  /path/to/dataset \
  --metric_output_dir    /path/to/output \
  --foveate_real
```

**With 2× downsampled real images:**
```bash
python generate_metrics.py \
  --generated_images_dir /path/to/generated \
  --images_dataset_path  /path/to/dataset \
  --metric_output_dir    /path/to/output \
  --downsample_real
```

**Smoke-test (no real data required):**
```bash
python generate_metrics.py --test
```

## `extract_inception_features.py`

Pre-extracts Inception features and saves them as a PKL cache file, using the same preprocessing as `generate_metrics.py`. Useful for large real-image datasets where extraction is expensive and should not be repeated per run.

### Args

| Arg | Default | Description |
|---|---|---|
| `--images_dir` | required | Directory of images to process. When `--real` (default), must contain `metadata_test.csv` with `image` and `prompt` columns. |
| `--output_dir` | required | Directory where the cache PKL is written. |
| `--real` / `--no-real` | `--real` | `--real`: treat as real images → saves `real_feats_cache.pkl`. `--no-real`: treat as generated images → saves `gen_feats_cache.pkl`. |
| `--foveate_real` | off | Apply per-image foveation (only with `--real`; requires `--masks_dir`). |
| `--masks_dir` | None | Directory of `mask_*.png` files matched positionally to sorted images (required when `--foveate_real`). |
| `--downsample_real` | off | Bicubic 2× downsample. |
| `--batch_size` | 64 | Batch size for Inception feature extraction. |
| `--device` | `cuda:0` / `cpu` | PyTorch device string. |

### Example invocations

**Pre-extract real image features:**
```bash
python extract_inception_features.py \
  --images_dir /path/to/dataset \
  --output_dir /path/to/output
```

**Pre-extract real image features with foveation:**
```bash
python extract_inception_features.py \
  --images_dir /path/to/dataset \
  --output_dir /path/to/output \
  --foveate_real \
  --masks_dir  /path/to/generated
```

**Pre-extract generated image features:**
```bash
python extract_inception_features.py \
  --images_dir /path/to/generated \
  --output_dir /path/to/output \
  --no-real
```
