\paragraph{Baselines.}
Beyond the na\"ive mixed-resolution baseline, we compare against two training-free methods
that, like ours, accelerate diffusion by reducing the number of tokens the DiT processes:
token merging \citep{bolya2023tomesd,wu2025tome} and RALU \citep{ralu2026}. For an
apples-to-apples comparison, we drive both with \emph{our} foveation mask in place of
their own token-selection heuristics, so that all methods operate on the same token layout
at the same token ratio, and leave every other component of each method intact. All arms
additionally share the same base model, sampler, guidance scale, prompt order, and
fixation points.
